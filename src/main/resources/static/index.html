Amounts are in minor units. €100 succeeds, €13 fails, and €99 simulates an accepted payment whose first response times out. Refreshing reconciles its final outcome.

04 / Inspect the evidence

Expected: repeating a request returns the same payment ID; a successful payment has one balanced ledger transaction; another merchant gets HTTP 404. Failed payments create no ledger entry.
